# Samples

Put a rhythm exported from your own CT-X5000 here (USB → save a user rhythm).
It serves two purposes:

* `../y2c.py ac7check <file>` — confirms the format model still round-trips.
* `../y2c.py convert ... --template <file>` — the container the converted
  rhythm is written into.

Factory Casio rhythms are the instrument maker's content, so none are
committed here.
